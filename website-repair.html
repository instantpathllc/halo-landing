How to Request a Repair

What we can review

Links and navigation

Broken links, incorrect destinations, and small navigation issues.

Content updates

Changes to existing text, business details, images, or button labels.

Mobile layout

Specific spacing, overflow, or layout problems that make a page difficult to use on a phone.

These are examples, not a guarantee that every website or issue is supported. We review the site and requested change before accepting work.

A clear scope before work begins

  1. Share the website address and describe one specific problem.
  2. We assess whether the issue fits a focused repair.
  3. We agree on the work, price, completion date, and any access needed before work begins.
  4. After the repair, you receive a summary of the changes and how to review them.

Full redesigns, new applications, and larger feature development are outside this focused service. Additional work requires a separate agreement.

Start with One Issue

Request a website review

If someone shared this page with you, reply to them and ask about a website repair from Instant Path LLC.

Include your website address, the page affected, and a short description of what is wrong and what you would like to happen instead. If the issue happens on a particular phone or browser, include that detail too.

Do not send passwords, payment details, or private customer information with your initial request. This page does not collect submissions or payments.
